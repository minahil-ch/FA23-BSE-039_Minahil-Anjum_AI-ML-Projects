# IntelliHire – AI Recruitment & Candidate Screening Platform

An AI-powered HR recruitment platform built with Django, Django REST Framework,
and Scikit-learn. HR staff can manage candidates, upload recruitment datasets,
train and compare multiple ML classification algorithms, predict whether a
candidate should be shortlisted, and view hiring analytics on a live dashboard.

Built as a university internship project (3 credit hours).

---

## Features

- **Authentication & Roles** – Custom user model with Admin / HR Manager / Recruiter roles
- **Candidate Management** – Full CRUD, resume upload, search & filter, status pipeline (Applied → Hired)
- **Dataset Management** – CSV upload, automatic validation report, one-click cleaning, download cleaned CSV
- **ML Training Pipeline** – Trains and compares 6 algorithms: Logistic Regression, Decision Tree,
  Random Forest, SVM, KNN, Naive Bayes. Evaluates with Accuracy, Precision, Recall, F1, ROC-AUC,
  Cross-Validation, Confusion Matrix, and Feature Importance. Automatically selects and saves
  the best model with `joblib`.
- **AI Prediction Engine** – HR enters a candidate's details in a form and gets an instant
  Selected/Rejected prediction with a confidence score and a plain-English explanation.
- **Prediction History** – Every prediction is logged and searchable.
- **Dashboard & Analytics** – KPI cards and Chart.js graphs: hiring trend, status distribution,
  department breakdown, and model accuracy comparison.

## Quick Start

```bash
# 1. Create and activate a virtual environment
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate

# 2. Install dependencies
pip install -r requirements.txt

# 3. Copy the environment file (SQLite works out of the box, no editing needed)
cp .env.example .env

# 4. Apply database migrations
python manage.py migrate

# 5. Load demo data (admin user + 60 sample candidates + a training CSV)
python manage.py seed_demo_data

# 6. Run the development server
python manage.py runserver
```

Visit **http://127.0.0.1:8000** and log in:

| Role | Username | Password |
|---|---|---|
| Admin | `admin` | `Admin@12345` |
| HR Manager | `hr_manager` | `Hr@12345` |

### Try the ML pipeline

1. Go to **Datasets → Upload Dataset** and upload `sample_data/sample_recruitment_dataset.csv`
   (generated automatically by the seed command).
2. Click **Clean Dataset**, then **Go to Model Training**.
3. Click **Train Models** — all 6 algorithms train and get compared automatically.
4. Go to **Model Comparison** to see metrics side by side; the best model is highlighted.
5. Go to **Predict Candidate**, fill in the form, and get a live AI prediction.

## Switching to PostgreSQL

Edit `.env`:

```
USE_POSTGRES=True
DB_NAME=intellihire_db
DB_USER=postgres
DB_PASSWORD=your_password
DB_HOST=localhost
DB_PORT=5432
```

Create the database (`createdb intellihire_db` or via `psql`), then re-run
`python manage.py migrate` and `python manage.py seed_demo_data`.


## Notes for your Viva / Report

- The **ML pipeline** lives entirely in `ml_engine/` and is fully decoupled from
  Django views — `train.py` and `predict.py` can be run and tested independently.
- `preprocessing.py` is shared by both training and prediction, which prevents
  "train/serve skew" (a common real-world ML bug where live predictions are
  processed differently than training data).
- The demo dataset's `selected` label is generated by a simple weighted-score
  rule (see `seed_demo_data.py`) purely so the pipeline has something realistic
  to train on out of the box. For a real submission, replace
  `sample_data/sample_recruitment_dataset.csv` with genuine/realistic HR data —
  the rest of the pipeline works unchanged with any CSV that has the same
  column names.
- The best model is picked by **F1 score** (a balance of precision and recall),
  which is generally a better single metric than raw accuracy for hiring
  decisions where the two classes may be imbalanced.
